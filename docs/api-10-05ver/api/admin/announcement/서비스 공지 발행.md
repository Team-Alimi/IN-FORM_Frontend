# 서비스 공지 발행

**임시저장이나 보관 상태의 공지를 사용자에게 노출합니다.**

- **Method / Endpoint: `POST /api/v1/admin/announcements/{announcementId}/publish`**
- **Auth Required: Required (Admin)**

> 등록할 때 `status: "PUBLISHED"` 로 보내면 이 호출이 필요 없습니다.
> 이 엔드포인트는 **초안으로 써 뒀던 공지를 나중에 올릴 때**와 **잘못 내린 것을 되살릴 때** 씁니다.

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |

## Path Variable

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| announcementId | Long | 공지 번호 | **필수** |

본문이 없습니다.

## Request Sample

```
POST /api/v1/admin/announcements/13/publish
```

# Response

[서비스 공지 등록.md](%EC%84%9C%EB%B9%84%EC%8A%A4%20%EA%B3%B5%EC%A7%80%20%EB%93%B1%EB%A1%9D.md) 의 응답과 **같은 모양**이고, 발행 후의 전체 상태가 나갑니다.

### 상태 전이

| 현재 | 발행 가능? |
|---|---|
| `DRAFT` | ✅ |
| `ARCHIVED` | ✅ (되살리기) |
| `PUBLISHED` | ❌ **400** |

> **이미 발행 중이면 400 입니다.** 멱등하게 통과시키면 버튼을 눌렀을 때
> "방금 발행됐다" 와 "이미 발행돼 있었다" 를 화면이 구분할 수 없습니다.

### ★ 최초 발행 시각은 유지됩니다

보관했다 다시 발행해도 `published_at` 은 **처음 발행한 시각 그대로**입니다.

사용자 목록이 `published_at` 최신순이라, 되살릴 때마다 시각이 바뀌면
**"잘못 내린 것을 되살렸을 뿐" 인 공지가 맨 위로 올라옵니다.**
새 안내로 알리고 싶으면 새로 작성하세요.

### 팝업 설정은 그대로 따라옵니다

보관할 때 팝업 지정을 끄지 않으므로, 되살리면 **팝업도 다시 뜹니다.**
원하지 않으면 발행 전에 `is_popup: false` 로 수정하세요.

발행했지만 종료일이 이미 지난 경우 — **상태는 `PUBLISHED` 인데 사용자에게는 보이지 않습니다.**

```json
{
  "success": true,
  "data": {
    "id": 14,
    "type": "GENERAL",
    "title": "지난 안내",
    "content": "...",
    "status": "PUBLISHED",
    "is_popup": false,
    "published_at": "2026-10-05T16:05:00+09:00",
    "ends_on": "2026-09-30",
    "created_by": 3,
    "created_at": "2026-09-20T09:00:00+09:00",
    "updated_at": "2026-10-05T16:05:00+09:00",
    "warnings": [
      "노출 종료일(2026-09-30)이 지났습니다. 발행 상태지만 목록·팝업에 나오지 않습니다 — 다시 노출하려면 종료일을 늘리거나 비우세요."
    ]
  }
}
```

**이 경고를 반드시 띄우세요.** 발행이 성공했고 상태도 `PUBLISHED` 라서,
경고가 없으면 운영자는 공지가 안 보이는 이유를 혼자 추적하게 됩니다.

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_STATE_TRANSITION | 현재 상태(PUBLISHED)에서 PUBLISHED 로는 바꿀 수 없습니다. | 이미 발행 중 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 403 | FORBIDDEN | 권한이 없습니다. | `ROLE_ADMIN` 이 아님 |
| 404 | ANNOUNCEMENT_NOT_FOUND | 존재하지 않는 서비스 공지입니다. | 없는 번호 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |
