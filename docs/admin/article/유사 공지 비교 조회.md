# 유사 공지 비교 조회

**중복 의심으로 판정된 두 공지의 상세를 나란히 내려줍니다. 관리자가 병합할지 한쪽을 버릴지 정하려면 제목·본문·기간·첨부를 눈으로 맞대 봐야 하기 때문입니다. "확인 필요" 목록이나 상세 화면의 중복 배지에서 이 화면으로 들어옵니다.**

- **Method / Endpoint: `GET /api/v1/admin/articles/{articleId}/similar`**
- **Auth Required: Required (Admin)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |

## Path Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| articleId | Long | 기준이 되는 공지 ID. 비교 대상은 서버가 `similar_article_id` 로 찾습니다 | **필수** |

> **비교 대상을 지정할 수 없습니다.** 크롤러/AI 가 판정해 `similar_article_id` 에 넣어 둔
> 한 건과만 비교합니다. 임의의 두 공지를 맞대 보는 용도가 아닙니다.

## Request Sample

```
GET /api/v1/admin/articles/42/similar
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | 응답 데이터 |
| data.similarity_score | Number | 중복 의심 점수 **0~100** (소수 2자리). 기준 공지의 값입니다. **미판정이면 필드가 빠집니다** |
| data.similar | Object | 비교 대상 공지 상세. **없으면 필드가 통째로 빠집니다** |
| data.article | Object | 기준 공지 상세 (관리자 공지 상세와 같은 구조) |
| data.article.id | Long | 공지 ID |
| data.article.source_type | String | `SCHOOL` \| `CLUB` |
| data.article.status | String | 검수 상태 |
| data.article.title | String | 제목 |
| data.article.content | String | 본문 **HTML** |
| data.article.summary | String | AI 생성 요약. 미생성이면 필드가 빠집니다 |
| data.article.starts_on | String | 시작일 (yyyy-MM-dd). 없으면 필드가 빠집니다 |
| data.article.ends_on | String | 마감일 (yyyy-MM-dd). 없으면 필드가 빠집니다 |
| data.article.published_at | String | 최초 배포 시각 (ISO-8601 offset). 없으면 필드가 빠집니다 |
| data.article.similarity_score | Number | 중복 의심 점수 0~100. 최상위 `data.similarity_score` 와 같은 값 |
| data.article.similar_article_id | Long | 중복 의심 상대 공지 ID |
| data.article.created_by | Long | 작성 관리자 ID. 크롤러 수집분은 필드가 빠집니다 |
| data.article.created_at | String | 생성 시각 (ISO-8601 offset) |
| data.article.updated_at | String | 내용 수정 시각 (ISO-8601 offset) |
| data.article.categories | Array | 분류 목록 |
| data.article.categories[].id | Long | 분류 ID |
| data.article.categories[].name | String | 분류 이름 |
| data.article.vendors | Array | 제공처 목록 |
| data.article.vendors[].id | Long | **연결 행의 ID** (`article_vendors.id`) |
| data.article.vendors[].vendor_id | Long | 제공처 ID |
| data.article.vendors[].vendor_name | String | 제공처 이름 |
| data.article.vendors[].source_url | String | 원본 게시글 URL. 없으면 필드가 빠집니다 |
| data.article.vendors[].external_key | String | 원본 게시판 글 번호. 없으면 필드가 빠집니다 |
| data.article.attachments | Array | 첨부 목록 (`id` 오름차순) |
| data.article.attachments[].id | Long | 첨부 ID |
| data.article.attachments[].file_url | String | 파일 URL |
| data.article.attachments[].original_name | String | 원본 파일명 |
| data.article.attachments[].content_type | String | MIME 타입. 없으면 필드가 빠집니다 |
| data.article.attachments[].size_bytes | Long | 파일 크기(바이트). 없으면 필드가 빠집니다 |

| data.article.status_logs[].id | Long | 이력 ID |
| data.article.status_logs[].from_status | String | 이전 상태. 최초 생성이면 필드가 빠집니다 |
| data.article.status_logs[].to_status | String | 바뀐 상태 |
| data.article.status_logs[].changed_by | Long | 변경한 관리자 ID. 없으면 시스템 |

| data.article.status_logs[].memo | String | 변경 사유. 없으면 필드가 빠집니다 |

| error | Object | 에러 정보 (성공 시 null) |

> **`data.similar` 의 하위 필드는 `data.article` 과 한 글자도 다르지 않습니다.**
> 위 표에서 접두어만 `data.similar.` 로 바꿔 읽으세요. 상세 **전체**를 양쪽 다 내려주는 이유는
> 본문·첨부·기간을 맞대 보지 않으면 어느 쪽을 남길지 정할 수 없기 때문입니다.

> **비교 대상이 없으면 `data.similar` 키가 아예 없습니다. `null` 이 아닙니다.**
> 구판 명세는 `"similar": null` 이라고 적고 있지만, 이 서비스는 null 필드를 응답에서 제거합니다.
> `data.similar === null` 로 분기하면 영원히 false 입니다 — `'similar' in data` 로 판정하세요.
> 같은 이유로 `data.similarity_score` 도 함께 사라질 수 있습니다.
>
> 이때도 **404 가 아니라 200** 입니다. "비교할 게 없다" 는 것 자체가 관리자에게 필요한 답이라
> 에러로 만들지 않습니다.

### `similar` 가 비는 두 가지 경우

| 경우 | `similarity_score` |
| --- | --- |
| 아직 유사 판정이 안 됨 (`similar_article_id` 없음) | 함께 비어 있음 |
| 상대 공지가 이미 병합·영구 삭제됨 | **값이 남아 있을 수 있음** |

> 두 번째가 함정입니다. 점수는 있는데 비교 대상이 없는 응답이 정상적으로 나옵니다.
> 화면이 "점수가 있으니 `similar` 도 있겠지" 로 가정하면 깨집니다.
> 다만 병합 경로는 흡수 직전에 그 공지를 가리키던 유사도를 지우므로, 이 상태는
> 앱을 거치지 않은 삭제에서 주로 생깁니다.

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | articleId: 값의 형식이 올바르지 않습니다. | 경로 변수가 숫자가 아님 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 403 | FORBIDDEN | 권한이 없습니다. | `ROLE_ADMIN` 이 아님 |
| 404 | ARTICLE_NOT_FOUND | 존재하지 않는 공지입니다. | **기준 공지**(`articleId`)가 없을 때만 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |

> 404 는 `articleId` 가 없을 때뿐입니다. 비교 대상 쪽이 사라진 것은 에러가 아니라
> `similar` 필드가 빠진 200 입니다.
