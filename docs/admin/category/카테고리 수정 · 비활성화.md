# 카테고리 수정 · 비활성화

**카테고리의 이름·정렬 값·활성 여부를 고칩니다. 부분 수정이며 보내지 않은 항목은 그대로 남습니다. 쓰이고 있는 카테고리는 삭제가 막히므로, 운영 중인 카테고리를 접는 조작은 사실상 전부 이 API 의 `is_active: false` 로 처리합니다.**

- **Method / Endpoint: `PATCH /api/v1/admin/categories/{categoryId}`**
- **Auth Required: Required (Admin)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |
| Content-Type | application/json | | **필수** |

## Path Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| categoryId | Long | 수정할 카테고리 ID | **필수** |

## Body Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| name | String | 새 이름. 최대 100자. **UNIQUE 라 다른 카테고리와 겹치면 `409`** | 선택 |
| sort_order | Integer | 새 정렬 값 | 선택 |
| is_active | Boolean | `false` = 비활성화, `true` = 다시 켜기 | 선택 |
| code | String | **바꿀 수 없습니다.** 현재 값과 같으면 무시, 다르면 `400` | 선택 |

### `null` 은 "그대로 두라" 입니다

보내지 않은(또는 `null` 인) 항목은 건드리지 않습니다. 빈 body `{}` 도 정상 요청이며,
아무것도 바뀌지 않은 채 현재 상태가 200 으로 돌아옵니다.

> `name` 에는 "지우기" 가 없습니다. `""` 를 보내면 지워지는 것이 아니라 `400` 입니다.

### `code` 를 되돌려 보내도 됩니다

| 요청 값 | 결과 |
| --- | --- |
| 생략 · `null` · `""` · 공백뿐 | 무시 |
| 현재 값과 같음 (**대소문자·앞뒤 공백 무시**) | 무시 — `"form_code"` 로 보내도 `FORM_CODE` 와 같은 값으로 봅니다 |
| 현재 값과 다름 | **`400 IMMUTABLE_FIELD`** |

`code` 는 엔티티가 `updatable = false` 라 보내도 UPDATE 문에 실리지 않지만, **다른** 값을 보낸 요청까지
조용히 넘기면 관리자가 200 을 받고 크롤러 연동 키가 바뀐 줄 압니다. 그래서 명시적으로 거부합니다.
DB 트리거 `trg_categories_10_immutable`(`IN001`)이 최후 방어로 남아 있습니다.

## Request Sample

```json
# 이름과 정렬만 변경
PATCH /api/v1/admin/categories/3
{ "name": "장학·학자금", "sort_order": 5 }
```

```json
# 비활성화 — 쓰이고 있어 삭제할 수 없는 카테고리를 접을 때
PATCH /api/v1/admin/categories/3
{ "is_active": false }
```

```json
# 관리 폼이 전체 값을 되돌려 보내는 경우 — code 가 같으면 통과합니다
PATCH /api/v1/admin/categories/3
{
  "name": "장학",
  "sort_order": 10,
  "is_active": true,
  "code": "scholarship"
}
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | 수정된 카테고리 |
| data.id | Long | 카테고리 ID |
| data.code | String | 계약 키 (항상 기존 값) |
| data.name | String | 이름 |
| data.is_active | Boolean | 활성 여부 |
| data.sort_order | Integer | 정렬 값 |
| data.in_use | Boolean | 공지 또는 사용자 관심분야가 이 카테고리를 쓰고 있는지. 요청 시점에 다시 계산합니다 |
| data.warning | String | **비활성화로 바뀐 경우에만** 채워집니다 |

> **`warning` 은 `is_active` 가 `true → false` 로 실제로 바뀐 요청에만 붙습니다.**
> 다시 켤 때(`false → true`), 이미 같은 값을 보낸 경우, 이름만 고친 경우에는 `null` 이라
> **응답에서 키 자체가 사라집니다.** 프론트는 `warning` 의 존재 여부로 분기해야 합니다.

> **비활성화는 절반만 듣습니다.** DB 트리거(`IN010`)가 막는 것은 사용자의 **신규 관심분야 선택**뿐입니다.
> 공지에 붙는 카테고리는 크롤러가 앱을 거치지 않고 직접 쓰는 경로라 여기서 막지 않습니다 —
> 막으면 AI 분류기가 비활성 코드를 내보내는 순간 수집이 통째로 멈추기 때문입니다.
> 그래서 제공처와 같은 2단계입니다: **앱에서 끄고, 크롤러 AI 카테고리 목록에서도 빼야** 합니다.
> `warning` 이 그 문장을 담아 내려오므로 반드시 노출하세요.
>
> 이미 그 카테고리가 붙어 있는 공지들은 그대로 유지됩니다. 비활성화는 소급하지 않습니다.

## Response Sample

이름만 바꾼 경우 — `warning` 이 없습니다.

```json
{
  "success": true,
  "data": {
    "id": 3,
    "code": "SCHOLARSHIP",
    "name": "장학·학자금",
    "is_active": true,
    "sort_order": 5,
    "in_use": true
  }
}
```

비활성화한 경우 — `warning` 이 붙습니다.

```json
{
  "success": true,
  "data": {
    "id": 3,
    "code": "SCHOLARSHIP",
    "name": "장학",
    "is_active": false,
    "sort_order": 10,
    "in_use": true,
    "warning": "이미 붙어 있는 공지 카테고리는 그대로 유지되고, 크롤러 AI 카테고리 목록에서도 이 코드를 빼야 새 공지에 더 이상 붙지 않습니다."
  }
}
```

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | IMMUTABLE_FIELD | 카테고리 코드는 등록 후 바꿀 수 없습니다. 크롤러가 이 값으로 카테고리 결과를 보냅니다. 바꿔야 한다면 새 카테고리를 만들고 기존 것은 비활성화하세요. | `code` 에 현재와 다른 값을 보냄 |
| 400 | INVALID_INPUT_VALUE | 카테고리 이름을 입력해 주세요. | `name` 에 `""` 또는 공백뿐인 문자열을 보냄 |
| 400 | INVALID_INPUT_VALUE | name: 카테고리 이름은 100자를 넘을 수 없습니다. | 길이 초과 (`code` 50자도 같은 코드) |
| 400 | INVALID_INPUT_VALUE | categoryId: 값의 형식이 올바르지 않습니다. | 경로 변수가 숫자가 아님 |
| 400 | MALFORMED_REQUEST | 요청 본문을 해석할 수 없습니다. | JSON 파싱 실패, `sort_order` 가 정수가 아님, `is_active` 가 boolean 이 아님 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 403 | FORBIDDEN | 권한이 없습니다. | 로그인은 했으나 `ROLE_ADMIN` 이 아님 |
| 404 | CATEGORY_NOT_FOUND | 존재하지 않는 카테고리입니다. | 그 ID 의 카테고리가 없음 |
| 409 | DUPLICATE_RESOURCE | 이미 쓰이고 있는 카테고리 이름입니다: {name} | 다른 카테고리가 그 이름을 쓰고 있음. **자기 이름을 그대로 다시 보내는 것은 중복이 아닙니다** |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |
