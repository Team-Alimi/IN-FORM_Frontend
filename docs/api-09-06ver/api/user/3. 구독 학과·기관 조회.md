# 구독 학과·기관 조회

**내가 구독한 학과·기관 목록을 조회합니다. 온보딩 2단계에서 체크박스의 초기 선택 상태를 그릴 때, 그리고 마이페이지 구독 관리 화면을 열 때 부릅니다. 선택한 id 뿐 아니라 표시명까지 함께 내려주므로, 이름을 얻기 위해 마스터 목록(`GET /vendors`)을 다시 부를 필요가 없습니다.**

- **Method / Endpoint: `GET /api/v1/users/me/vendors`**
- **Auth Required: Required (User)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |

## Request Sample

```
GET /api/v1/users/me/vendors
Authorization: Bearer eyJ...
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Array | **객체가 아니라 배열입니다.** 선택한 항목 목록 |
| data[].id | Long | `vendors.id` |
| data[].name | String | 제공처 이름 (예: `컴퓨터공학과`) |
| error | Object | 에러 정보 (성공 시 키 자체가 빠짐) |

> **`data` 가 배열입니다.** 이 도메인의 다른 목록 API 와 달리 `data.content` / `data.page_info`
> 로 감싸지 않습니다. 페이징도 없습니다 — 개인 선택은 많아야 십수 개라 전부 내려줍니다.

> **`initial`·`type`·`is_active` 는 내려가지 않습니다.** id 와 이름 두 개뿐입니다.
> 축약 표기나 유형 배지가 필요하면 마스터 목록(`GET /vendors`, 비로그인 허용)에서 가져오세요.

> **정렬은 이름 오름차순(`name ASC`)입니다.** 선택한 순서도 아니고 id 순도 아닙니다.
> 저장 요청에 보낸 배열 순서는 보존되지 않습니다.

> **선택이 없으면 빈 배열 `[]` 입니다.** `null` 이 아니라 빈 배열이므로 그대로 순회하면 됩니다.
> 온보딩을 아직 하지 않은 신규 계정이 이 상태입니다.

## Response Sample

```json
{
  "success": true,
  "data": [
    { "id": 7, "name": "교무처" },
    { "id": 3, "name": "소프트웨어학과" }
  ]
}
```

선택이 하나도 없을 때:

```json
{
  "success": true,
  "data": []
}
```

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료·무효화됨 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |

> **이 조회는 `USER_NOT_FOUND` 를 내지 않습니다.** 사용자 행을 확인하지 않고 관계 테이블만 읽기
> 때문입니다. 없는 사용자의 토큰으로 부르면 `404` 가 아니라 빈 배열이 내려갑니다.
> 같은 그룹의 저장(`PUT`)·프로필(`GET /users/me`) 은 사용자 행을 확인하므로 `404` 가 있습니다.
