# 댓글 작성

**공지에 댓글을 답니다. 답글(대댓글)은 없습니다 — 댓글은 공지 하나에 달리는 평면 목록입니다.**

- **Method / Endpoint: `POST /api/v1/articles/{articleId}/comments`**
- **Auth Required: Required (User)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |
| Content-Type | application/json | | **필수** |

## Path Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| articleId | Long | 댓글을 달 공지 ID | **필수** |

## Body Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| content | String | 댓글 본문. **1~1000자**, 순수 텍스트 | **필수** |

- 공백만 있는 문자열은 `400` 입니다
- HTML 태그는 저장은 되지만 화면에서 **이스케이프 렌더링**합니다
- **`parent_id` 는 없습니다.** 예전 명세에 있었으나 답글 기능과 함께 제거됐습니다.
  보내면 무시되고 400 도 아닙니다

## Request Sample

```json
POST /api/v1/articles/42/comments
{ "content": "신청 기한 연장됐나요?" }
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | 방금 작성한 댓글 |
| data.id | Long | 댓글 고유 ID |
| data.content | String | 본문 |
| data.author | Object | 작성자 |
| data.author.id | Long | 작성자 ID. **탈퇴자는 `null`** |
| data.author.name | String | 작성자 이름. 탈퇴자는 `"탈퇴한 사용자"` |
| data.created_at | String | 작성 일시 (ISO-8601 offset) |
| data.edited | Boolean | 수정된 적이 있는지. 작성 직후는 항상 `false` |
| data.is_mine | Boolean | 보는 사람이 작성자인지. 작성 직후는 항상 `true` |
| error | Object | 에러 정보 (성공 시 null) |

> 목록(`GET /articles/{id}/comments`) 항목과 **같은 모양**입니다. 화면이 방금 쓴 댓글을
> 목록에 그대로 끼워 넣을 수 있게 하려고 맞춰 두었습니다.

## Response Sample

```json
{
  "success": true,
  "data": {
    "id": 71,
    "content": "신청 기한 연장됐나요?",
    "author": { "id": 5, "name": "홍길동" },
    "created_at": "2026-08-22T14:02:00+09:00",
    "edited": false,
    "is_mine": true
  },
  "error": null
}
```

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | 댓글 내용을 입력해 주세요. | `content` 가 비었거나 공백뿐 |
| 400 | INVALID_INPUT_VALUE | 댓글은 1000자를 넘을 수 없습니다. | 길이 초과 |
| 400 | MALFORMED_REQUEST | 요청 본문을 읽을 수 없습니다. | JSON 파싱 실패 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 404 | ARTICLE_NOT_FOUND | 존재하지 않는 게시글입니다. | 공지가 없거나 볼 수 없는 상태 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |

> **볼 수 있으면 쓸 수 있습니다.** 댓글 작성의 공지 가시성 기준은 북마크와 같습니다 —
> 상세를 열 수 있는 공지면 댓글도 달 수 있습니다. 북마크에서 재검수 중인 공지를 열었는데
> 댓글창만 막혀 있으면 사용자는 이유를 알 수 없기 때문입니다.
