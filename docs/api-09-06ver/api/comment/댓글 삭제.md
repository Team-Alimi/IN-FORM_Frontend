# 댓글 삭제

**본인이 쓴 댓글을 지웁니다. 행째 사라지며 "삭제된 댓글입니다" 자리는 남지 않습니다.**

- **Method / Endpoint: `DELETE /api/v1/comments/{commentId}`**
- **Auth Required: Required (User)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |

## Path Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| commentId | Long | 지울 댓글 ID | **필수** |

## Request Sample

```
DELETE /api/v1/comments/71
```

요청 body 가 없습니다.

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | **항상 null** — 돌려줄 것이 없습니다 |
| error | Object | 에러 정보 (성공 시 null) |

> `default-property-inclusion: non_null` 이라 성공 응답에서 `data` 키 자체가 빠집니다.
> `success` 만 보세요.

## Response Sample

```json
{
  "success": true
}
```

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | 유효하지 않은 입력 값입니다. | `commentId` 가 숫자가 아님 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 403 | FORBIDDEN | 권한이 없습니다. | **남의 댓글**을 지우려 함 |
| 404 | COMMENT_NOT_FOUND | 존재하지 않는 댓글입니다. | 없거나 이미 지워짐 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |

> **되살릴 수 없습니다.** 답글이 없어지면서 자리를 남기는 삭제(soft delete)도 함께 사라졌습니다 —
> 아래에 매달린 것이 없으므로 지워도 남의 글이 함께 없어지지 않고, 따라서 껍데기를 남길 이유가 없습니다.
> 화면에서 확인 단계를 두는 것을 권합니다.

> 공지의 `comment_count` 는 DB 트리거가 알아서 내립니다. 클라이언트가 따로 세지 마세요.
