# 댓글 목록 조회

**공지에 달린 댓글을 시간순으로 조회합니다. 답글(대댓글)이 없어 중첩 구조 없는 평면 목록입니다.**

- **Method / Endpoint: `GET /api/v1/articles/{articleId}/comments`**
- **Auth Required: Required (User)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |

## Path Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| articleId | Long | 공지 ID | **필수** |

## Query Param

| Name | Type | Description | Required | Default |
| --- | --- | --- | --- | --- |
| page | Integer | 페이지 번호 (**1부터**) | 선택 | 1 |
| size | Integer | 페이지당 건수 (최대 50) | 선택 | 20 |

> **`sort` 는 받지 않습니다.** 정렬은 작성 시간 오름차순 고정입니다.
> 보내도 400 이 아니라 **무시**됩니다 — 대화는 시간순으로 읽는 것이라 뒤집을 이유가 없습니다.

## Request Sample

```
GET /api/v1/articles/42/comments
GET /api/v1/articles/42/comments?page=2&size=20
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | 응답 데이터 |
| data.page_info | Object | 페이징 정보 |
| data.page_info.current_page | Integer | 현재 페이지 (1부터) |
| data.page_info.size | Integer | 페이지당 건수 |
| data.page_info.total_pages | Integer | 전체 페이지 수 |
| data.page_info.total_items | Long | **전체 댓글 수** |
| data.page_info.has_next | Boolean | 다음 페이지 존재 여부 |
| data.content | Array | 댓글 목록 (작성 시간 오름차순) |
| data.content[].id | Long | 댓글 고유 ID |
| data.content[].content | String | 본문 |
| data.content[].author | Object | 작성자 |
| data.content[].author.id | Long | 작성자 ID. **탈퇴자는 `null`** |
| data.content[].author.name | String | 이름. 탈퇴자는 `"탈퇴한 사용자"` |
| data.content[].created_at | String | 작성 일시 (ISO-8601 offset) |
| data.content[].edited | Boolean | 수정된 적이 있는지 |
| data.content[].is_mine | Boolean | **보는 사람 기준**. 수정·삭제 버튼 노출에 씁니다 |
| error | Object | 에러 정보 (성공 시 null) |

> **삭제된 댓글은 목록에 없습니다.** 지우면 행째 사라지므로 "삭제된 댓글입니다" 자리도 남지 않습니다.
> 공지의 `comment_count` 도 같은 기준으로 셉니다.

> **탈퇴한 사용자의 댓글은 남습니다.** 지우면 대화 흐름이 끊기기 때문입니다.
> 대신 `author.id` 가 `null` 이고 이름이 `"탈퇴한 사용자"` 로 내려갑니다 —
> `author.id` 로 프로필을 링크하는 화면은 `null` 을 반드시 처리해야 합니다.

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | 유효하지 않은 입력 값입니다. | `articleId` 가 숫자가 아님 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 404 | ARTICLE_NOT_FOUND | 존재하지 않는 게시글입니다. | 공지가 없거나 볼 수 없는 상태 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |
