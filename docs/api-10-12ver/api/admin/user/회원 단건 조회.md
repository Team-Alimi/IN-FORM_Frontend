# 회원 단건 조회

**회원 한 명의 정보를 조회합니다. 관리자 페이지에서 목록의 한 줄을 눌러 상세 패널을 열 때, 그리고 권한 변경 직후 화면을 다시 그릴 때 부릅니다. 응답 형태는 목록 한 줄(`AdminUserSummary`)과 완전히 같습니다 — 목록에 없는 추가 필드는 없습니다.**

- **Method / Endpoint: `GET /api/v1/admin/users/{userId}`**
- **Auth Required: Required (Admin)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 관리자 Access Token | **필수** |

## Path Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| userId | Long | 조회할 회원 ID | **필수** |

## Request Sample

```
GET /api/v1/admin/users/7
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | 회원 정보 |
| data.id | Long | 회원 고유 ID |
| data.email | String | 이메일 (**소문자로만 저장**) |
| data.name | String | 이름. 값이 없으면 **필드 자체가 빠집니다** |
| data.role | String | `USER` \| `ADMIN` |
| data.status | String | `ACTIVE` \| `WITHDRAWN` |
| data.onboarding_completed | Boolean | 온보딩 완료 여부 |
| data.created_at | String | 가입 일시 (ISO-8601 offset) |
| data.withdrawn_at | String | 탈퇴 일시. **활성 회원은 필드 자체가 빠집니다** |

> **`null` 필드는 응답에서 아예 빠집니다** (`default-property-inclusion: non_null`).
> `name` 과 `withdrawn_at` 이 여기 해당합니다. **탈퇴 여부는 `status` 로 판단**하세요 —
> `withdrawn_at` 은 활성 회원에게 `null` 이 아니라 아예 없습니다.
> 성공 응답에는 `error` 키도, 실패 응답에는 `data` 키도 없습니다.

> **회원의 구독 학과·관심 분류·알림 설정은 여기에 없습니다.** 이 API 는 권한 관리 화면이
> 대상을 사람으로 특정하는 데 필요한 최소 정보만 돌려줍니다.

> **탈퇴한 회원도 200 으로 조회됩니다.** 탈퇴는 soft delete 라 행이 남아 있고,
> 이름·이메일도 가리지 않습니다. 조회가 404 가 되는 것은 애초에 없는 ID 일 때뿐입니다.

## Response Sample

```json
{
  "success": true,
  "data": {
    "id": 7,
    "email": "kim@inha.ac.kr",
    "name": "김인하",
    "role": "USER",
    "status": "ACTIVE",
    "onboarding_completed": true,
    "created_at": "2026-03-02T09:00:00+09:00"
  }
}
```

탈퇴한 회원:

```json
{
  "success": true,
  "data": {
    "id": 5,
    "email": "gone@inha.ac.kr",
    "name": "탈퇴회원",
    "role": "ADMIN",
    "status": "WITHDRAWN",
    "onboarding_completed": false,
    "created_at": "2026-02-11T13:24:00+09:00",
    "withdrawn_at": "2026-07-30T18:02:00+09:00"
  }
}
```

> 위처럼 `status: "WITHDRAWN"` 인데 `role: "ADMIN"` 인 조합이 실제로 존재합니다. 관리자가 탈퇴하면
> 계정만 `WITHDRAWN` 이 되고 권한은 그대로 남기 때문입니다. 그래서 권한 변경 API 는
> **탈퇴 회원의 강등은 허용**합니다.

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | userId: 값의 형식이 올바르지 않습니다. | 경로 변수가 숫자가 아님 (`/admin/users/abc`) |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 403 | FORBIDDEN | 권한이 없습니다. | 로그인은 되었으나 `ROLE_ADMIN` 이 아님 |
| 404 | USER_NOT_FOUND | 존재하지 않는 사용자입니다. | 해당 ID 의 회원이 없음 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |
