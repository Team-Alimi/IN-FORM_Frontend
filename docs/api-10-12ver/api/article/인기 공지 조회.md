# 인기 공지 조회

**북마크 수가 가장 많은 공지를 상위 몇 건만 내려 줍니다. 홈 화면 상단의 고정 영역을 그리는 데 쓰는 호출이라 페이징도 필터도 없습니다. 항목의 모양은 공지 목록의 한 칸과 완전히 같고, 봉투만 다릅니다 — `data` 가 곧 배열입니다.**

- **Method / Endpoint: `GET /api/v1/articles/popular`**
- **Auth Required: Not Required**

> **비로그인도 부를 수 있습니다.** 홈 화면이 캘린더 페이지이고 이 목록이 그 상단에 그려지기 때문입니다.
> 캘린더만 열고 이것을 닫으면 비로그인 홈이 반쪽만 나옵니다.
>
> **토큰을 보내면 개인화 값이 채워지고, 안 보내면 `is_bookmarked` 가 `false`** 입니다.
> 로그인 여부와 무관하게 목록 내용 자체는 같습니다.
>
> **여기서 상세로 넘어가면 로그인 벽을 만납니다.** `GET /articles/{id}` 는 여전히 로그인이 필요해서
> 비로그인 사용자가 항목을 누르면 `401` 입니다. 화면에서 로그인 유도로 받아 주세요.

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | 선택 |

## Query Param

| Name | Type | Description | Required | Default |
| --- | --- | --- | --- | --- |
| limit | Integer | 가져올 건수. **1~20 범위로 보정됩니다** | 선택 | 5 |

> **`limit` 기본값은 5 입니다.** 구판 명세에는 "기본 10, 최대 50" 으로 적혀 있지만 코드는 다릅니다.
> 홈 화면의 고정 영역이 다섯 칸이라 그 수에 맞춰 두었습니다.

> **범위를 벗어난 `limit` 은 에러가 아니라 보정입니다.** `limit=100` 을 보내면 400 이 아니라
> **20건이 담긴 200** 이 옵니다. `limit=0` 이나 음수는 1 로 올라갑니다.
> 요청한 개수를 그대로 믿고 화면을 그리면 안 되고, 실제로 받은 배열 길이를 봐야 합니다.
> 숫자로 해석되지 않는 값(`limit=abc`)만 `400 INVALID_INPUT_VALUE` 입니다.

**필터가 없습니다.** `source_type` · `category_id` · `interest_only` 는 이 엔드포인트에서 받지 않습니다.
보내도 조용히 무시됩니다. 학교·동아리 통합이며 개인 관심 분야와 무관한 **전체 기준 순위**입니다.

## Request Sample

```
# 기본 5건
GET /api/v1/articles/popular

# 10건
GET /api/v1/articles/popular?limit=10
```

# Response

### 순위 기준

`bookmark_count` 내림차순, 동점이면 `id` 내림차순(최신 우선)입니다.
조회수는 순위에 들어가지 않습니다. tie-breaker 로 `id` 를 고정해 두어야 같은 요청이
매번 같은 순서를 돌려줍니다 — 북마크 수는 0~5 에 몰려 동점이 흔합니다.

기간 개념이 없습니다. "최근 7일 인기" 가 아니라 **누적 북마크 수 기준**입니다.

### 노출 기준

`status = PUBLISHED` 인 공지만 나옵니다. 재검수로 내려간 공지는 여기서 빠지므로
**`under_review` 는 항상 `false`** 입니다.

마감 여부는 보지 않습니다. **이미 마감된 공지(`deadline_status: "CLOSED"`)도 북마크가 많으면 올라옵니다.**
마감된 것을 감추고 싶다면 프론트가 `deadline_status` 로 걸러야 합니다.

### `deadline_status` 분류 기준

| 값 | 조건 |
| --- | --- |
| `UPCOMING` | 오늘 < `starts_on` |
| `OPEN` | 진행 중 (`starts_on` 만 있고 `ends_on` 이 없는 경우 포함) |
| `CLOSING_SOON` | `ends_on` 까지 **3일 이내** |
| `CLOSED` | 오늘 > `ends_on` |
| `ALWAYS` | `starts_on` · `ends_on` 이 둘 다 없음 (상시) |

DB 컬럼이 아니라 조회 시각에 계산하는 파생값입니다.

### Response Param

> **`data` 가 배열입니다.** 페이징이 없으므로 `data.content` 도 `data.page_info` 도 없습니다.
> 목록 API 와 같은 파서를 쓰면 여기서 깨집니다.

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Array | 인기 공지 목록. 없으면 빈 배열 |
| data[].id | Long | 게시글 고유 ID |
| data[].source_type | String | `SCHOOL` \| `CLUB` |
| data[].title | String | 제목 |
| data[].summary | String | AI 생성 요약. **미생성이면 필드 자체가 없습니다** |
| data[].published_at | String | 발행 일시 (ISO-8601 offset) |
| data[].starts_on | String | 시작일 (yyyy-MM-dd). **없으면 필드 자체가 없습니다** |
| data[].ends_on | String | 마감일 (yyyy-MM-dd). **없으면 필드 자체가 없습니다** |
| data[].deadline_status | String | 마감 상태 (위 표) |
| data[].bookmark_count | Integer | 전체 북마크 수. **이 값이 순위 기준입니다** |
| data[].comment_count | Integer | 댓글 수. 삭제된 댓글(자리만 남은 것 포함)은 세지 않습니다 |
| data[].view_count | Long | 조회 수 |
| data[].is_bookmarked | Boolean | 호출한 사용자의 북마크 여부 |
| data[].has_attachment | Boolean | 첨부 존재 여부 (클립 아이콘용) |
| data[].under_review | Boolean | 재검수 배지. **이 목록에서는 항상 false** |
| data[].vendors | Array | 제공처 목록. 없으면 빈 배열 |
| data[].vendors[].id | Long | 제공처 ID |
| data[].vendors[].name | String | 제공처 이름 |
| data[].vendors[].initial | String | 축약 표시 ("컴퓨터공학과" → "컴공") |
| data[].vendors[].type | String | `SCHOOL` \| `CLUB` |
| data[].categories | Array | 분류 목록. 없으면 빈 배열 |
| data[].categories[].id | Long | 분류 ID |
| data[].categories[].name | String | 분류 이름 |
| error | Object | 에러 정보 (성공 시 null) |

> **`null` 인 필드는 응답에서 아예 빠집니다** (`default-property-inclusion: non_null`).
> `summary` · `starts_on` · `ends_on` 이 여기 해당합니다. 키의 존재 여부로 판단하세요.

> 목록의 `vendors` 와 같은 규칙으로 **같은 제공처는 한 번만** 나옵니다.
> 원본 링크(`source_url`)는 상세 응답에만 있습니다.

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | limit: 값의 형식이 올바르지 않습니다. | `limit` 이 정수로 해석되지 않음. **범위를 벗어난 정수는 에러가 아니라 보정입니다** |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료. **인기 공지도 비로그인으로 열리지 않습니다** |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |
