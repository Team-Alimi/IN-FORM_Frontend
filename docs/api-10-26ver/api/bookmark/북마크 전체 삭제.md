# 북마크 전체 삭제

**사용자의 북마크를 한 번에 비웁니다. `source_type` 을 주면 그 출처의 북마크만 지우고, 생략하면 전부 지웁니다. 마이페이지의 "저장한 공지 모두 지우기" 버튼이 호출합니다. 지운 개수를 돌려주므로 화면에서 "12개를 삭제했습니다" 로 확인시켜 줄 수 있습니다.**

- **Method / Endpoint: `DELETE /api/v1/bookmarks`**
- **Auth Required: Required (User)**

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 서비스 Access Token | **필수** |

## Query Param

| Name | Type | Description | Required | Default |
| --- | --- | --- | --- | --- |
| source_type | String | `SCHOOL` \| `CLUB`. 그 출처의 북마크만 삭제 | 선택 | - |

> **`source_type` 을 생략하면 북마크가 전부 지워집니다.** 안 보내는 것이 "아무것도 안 지움" 이 아니라
> "전부 지움" 입니다. 파라미터를 조건부로 붙이는 코드에서 값이 `undefined` 가 되어 빠지면
> 사용자가 학교 공지만 지우려다 전부 잃습니다. 프론트에서 값이 비었을 때의 분기를 반드시 확인하세요.

> `source_type` 은 **대문자만** 받습니다. `club` 처럼 소문자로 보내면 `400 INVALID_INPUT_VALUE` 입니다.

### 되돌릴 수 없습니다

행을 실제로 지웁니다. 휴지통도 복구 API 도 없습니다.
그래서 응답에 `removed_count` 를 담아 두었습니다 — **실행 전 확인 다이얼로그는 프론트의 몫입니다.**

### 다른 사용자와 다른 출처에는 손대지 않습니다

`user_id` 조건이 항상 걸려 있어 남의 북마크는 지워지지 않습니다.
북마크가 지워지면 공지의 `bookmark_count` 도 행 단위 트리거가 함께 내립니다 —
일괄 삭제여도 개수가 어긋나지 않습니다. 공지 자체는 삭제되지 않습니다.

## Request Sample

```
# 전부 삭제
DELETE /api/v1/bookmarks
Authorization: Bearer {access_token}

# 학교 공지 북마크만 삭제
DELETE /api/v1/bookmarks?source_type=SCHOOL

# 동아리 공지 북마크만 삭제
DELETE /api/v1/bookmarks?source_type=CLUB
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data | Object | 응답 데이터 |
| data.removed_count | Integer | 실제로 지운 북마크 개수. 지울 게 없으면 `0` |
| error | Object | 에러 정보. **성공 시 키 자체가 없음** |

> **지울 북마크가 하나도 없어도 `200` 이고 `removed_count` 는 `0`** 입니다. 오류가 아닙니다.
> `0` 은 `null` 이 아니므로 키는 그대로 내려옵니다 — 빈 결과에서 필드가 사라지는 일은 없습니다.

> `data` 는 `removed_count` 하나만 가진 객체입니다. 남은 북마크 수나 목록은 내려오지 않으므로,
> 삭제 후 화면을 갱신하려면 `GET /api/v1/bookmarks` 를 다시 부르거나 로컬 목록을 비워야 합니다.

## Response Sample

```json
{
  "success": true,
  "data": {
    "removed_count": 12
  }
}
```

지울 게 없었던 경우.

```json
{
  "success": true,
  "data": {
    "removed_count": 0
  }
}
```

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT_VALUE | source_type: 값의 형식이 올바르지 않습니다. | `SCHOOL` · `CLUB` 이 아닌 값. 소문자도 여기 해당합니다 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 없음·만료 |
| 409 | RESOURCE_BUSY | 요청이 일시적으로 충돌했습니다. 잠시 후 다시 시도해 주세요. | 북마크 수를 갱신하는 트리거가 같은 공지 행에서 경합한 경우. 지울 행이 많을수록 확률이 올라갑니다. **재시도하면 성공하는 실패**라 5xx 와 구분해 둡니다 |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |

> 재시도할 때는 이미 지워진 만큼이 빠진 상태라 `removed_count` 가 처음보다 작게 나옵니다.
> 두 응답의 값을 더하지 말고 마지막 응답만 사용자에게 보여 주세요.
