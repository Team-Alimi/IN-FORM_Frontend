# 서비스 공지 목록 조회

**운영팀이 앱 사용자에게 알리는 안내(점검·업데이트·이벤트 등)의 목록입니다. 학교·동아리에서 수집해 온 공지(`/articles`)와는 완전히 다른 데이터입니다.**

- **Method / Endpoint: `GET /api/v1/announcements`**
- **Auth Required: Not Required**

> **왜 비로그인인가** — 점검 공지는 로그인이 안 되는 상황에서 가장 필요합니다.
> 인증을 걸면 "로그인이 안 됩니다" 를 알리는 공지를 로그인해야 볼 수 있게 됩니다.

# Request

## Request Header

| Name | Value | Description | Required |
| --- | --- | --- | --- |
| Authorization | Bearer {access_token} | 있어도 되고 없어도 됩니다. 응답은 동일합니다 | 선택 |

## Query Param

| Name | Type | Description | Required |
| --- | --- | --- | --- |
| page | Integer | 1부터. 기본값 `1` | 선택 |
| size | Integer | 기본값 `20` | 선택 |

> **`sort` 는 받지 않습니다.** 보내도 무시됩니다. 정렬은 **최신 발행순 고정**입니다
> (`published_at DESC`, 같으면 `id DESC`).

### ★ 고정(상단 고정) 개념이 없습니다

이 목록은 **팝업으로 지정된 공지를 위로 올리지 않습니다.** 팝업 여부는 목록 표시와 무관하며,
그래서 응답에 `is_popup` 필드 자체가 없습니다.

지금 띄울 팝업은 **별도 엔드포인트**가 알려 줍니다 → [공지 팝업 조회.md](%EA%B3%B5%EC%A7%80%20%ED%8C%9D%EC%97%85%20%EC%A1%B0%ED%9A%8C.md)

## Request Sample

```
GET /api/v1/announcements?page=1&size=20
```

# Response

## Response Param

| name | type | 비고 |
| --- | --- | --- |
| success | Boolean | 요청 성공 여부 |
| data.content | Object[] | 공지 목록. 없으면 빈 배열 |
| data.content[].id | Long | 공지 번호. 상세 조회에 씁니다 |
| data.content[].type | String | `MAINTENANCE`(점검) \| `UPDATE`(업데이트) \| `EVENT`(이벤트) \| `GENERAL`(일반) |
| data.content[].title | String | 제목. 최대 500자 |
| data.content[].published_at | String | 발행 일시 (ISO-8601 offset) |
| data.page_info | Object | 페이징 정보. [00-common.md](../00-common.md) 공통 규격 |

> **본문(`content`)은 목록에 실리지 않습니다.** 공지가 쌓일수록 응답이 선형으로 커지기 때문입니다.
> 본문은 상세 조회에서 받습니다.

> **`type` 은 배지 색을 고르는 용도입니다.** 동작 차이는 없습니다 —
> 점검 공지가 팝업으로 뜨고 이벤트 공지가 안 뜨는 식의 규칙은 유형이 아니라 팝업 지정이 정합니다.

### 이 목록에 나오는 조건

```
상태 = 발행 중
AND (노출 시작일이 없거나  시작일 <= 오늘)
AND (노출 종료일이 없거나  종료일 >= 오늘)
```

- 임시저장·보관 공지는 나오지 않습니다
- **시작일이 미래인 예약 공지도 나오지 않습니다**
- **종료일이 지난 공지는 사라집니다.** "지난 안내" 를 계속 보여 줘야 한다면 운영팀이 종료일을 비워 두어야 합니다
- 기준일은 **KST** 입니다. 경계 날짜는 **포함**입니다(시작일 == 오늘, 종료일 == 오늘 모두 노출)

  "data": {

    "page_info": {

# Error

| HTTP Status | Code | Message | Description |
| --- | --- | --- | --- |
| 500 | INTERNAL_SERVER_ERROR | 서버 내부 오류가 발생했습니다. | 서버 측 처리 오류 |

> 인증이 필요 없고 입력값도 페이징뿐이라 **4xx 가 거의 나지 않습니다.**
> `page`·`size` 에 숫자가 아닌 값을 보내면 `400 INVALID_INPUT_VALUE` 입니다.
